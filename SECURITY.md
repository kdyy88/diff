# Security Policy

## Reporting a vulnerability

Please do not open a public issue for suspected security vulnerabilities.

Instead, report the issue privately to the project maintainer through the repository hosting platform and include:

- a short description of the issue
- reproduction steps
- affected endpoints or files
- any suggested mitigation if available

## Scope notes

This repository is currently a local-first prototype. It does not yet include:

- authentication
- authorization
- tenant isolation
- hardened file retention controls

Please keep that prototype scope in mind when evaluating risk and deployment readiness.
