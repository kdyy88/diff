# Code of Conduct

## Our pledge

We want PDF Flow Diff to be a welcoming, respectful project for contributors of all experience levels.

## Expected behavior

- Be respectful and constructive.
- Assume good intent and clarify before escalating.
- Focus feedback on the work, not the person.
- Share context generously, especially when discussing tricky technical tradeoffs.

## Unacceptable behavior

- Harassment, discrimination, or personal attacks
- Trolling or deliberately disruptive behavior
- Publishing private information without permission

## Enforcement

Project maintainers may remove comments, issues, or contributions that violate this code of conduct.

If you experience or witness a serious issue, open a private report with the project maintainer through the repository hosting platform.
